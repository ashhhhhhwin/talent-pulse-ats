# TalentPulse ATS

React + Tailwind HR platform for resume parsing, similarity scoring, interview pipeline, and offer release.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Features

- **Dashboard** — TalentPulse-style KPIs, top matches, AI resume CTA
- **Upload & Parse Resume** — drag/drop PDF/DOC/DOCX/TXT with mock NLP parsing
- **Candidates & Scoring** — similarity scores vs open jobs
- **Interview Pipeline** — Jira-style kanban across interview rounds
- **Job Openings** — listings with ranked matches
- **Offers** — release offer and mark hired

Sample resume: `public/sample-resume.txt`
